# 笔记主题交互原型

用于对比三个已生成的视觉方向，独立于正式博客代码和内容。

- 目录工作台：常驻笔记列表、标签筛选、正文目录。
- 纸感手记：暖白纸色、宋体标题、分组笔记索引。
- 专注阅读：收起常驻列表，通过抽屉搜索和切换笔记。

三个主题共用同一组示例笔记，切换时保留当前选中内容和未保存的编辑。支持搜索标题和正文、新建、编辑 Markdown、取消、保存示例、代码复制、目录跳转、手机宽度预览、查看视觉稿和重置示例。Cmd/Ctrl+K 搜索，Cmd/Ctrl+S 保存，Esc 关闭抽屉或视觉稿。

演示保存只保留在当前页面的内存中，刷新会恢复示例。未连接 GitHub、登录或正式博客数据，不修改现有 `public/blogs`。

开发：`npm run dev -- --host 127.0.0.1 --port 2026 --strictPort`。

构建：`npm run build`。

本地地址：`http://127.0.0.1:2026/`。通过 `?theme=workspace`、`?theme=journal`、`?theme=focus` 可直接进入对应主题。

验证：生产构建通过，三个主题的 React 初始渲染通过，本地 HTTP 页面响应通过。浏览器自动化因访问限制被中止，没有进行浏览器交互验证或截图对照；详见 `design-qa.md`。
